# 商品管理

## 1. 目标

维护商品主数据台账，支持按名称/上架状态检索，支持新增、编辑、删除与批量操作。

## 2. 功能范围

1. 商品列表：编码、名称、分类、上架状态、销售单价、库存数量；按名称与状态筛选；分页。
2. 新增/编辑弹窗：基本信（编码/名称/分类/状态）、价格与库存（单价/库存）、补充说明（负责人/备注）；双列 800px。
3. 删除与批量选择（每页可勾选，删除末页回退）。

## 3. 非目标

- 不接真实后端接口：本轮用明确的演示数据，接口缺失处标注。
